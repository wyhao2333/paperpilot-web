# PaperPilot Web

一个可在 Windows 本地测试、在 Ubuntu 自托管的文献阅读器：上传 PDF，按段阅读英文与中文译文，并保存笔记和阅读进度。

本目录是独立应用，原 Zotero 插件和 ANNA_APP 不参与运行。当前版本为 `0.2.1`。

## 本机启动

需要安装安全补丁后的 **Python 3.11+** 和 **Node.js 24.22.1+**（含 npm）。Docker 使用 Python 3.12.15，镜像支持 amd64 和 arm64。

在本目录打开终端：

```powershell
# Windows
python run.py
```

```bash
# Ubuntu：先安装 Python 的 venv 支持，并准备 Node.js 24
sudo apt-get install python3-venv
python3 run.py
```

首次运行会在本目录建立 `.venv`、安装 Python / Node 依赖并构建前端。随后访问：

**<http://localhost:8765>**

本机直接进入管理员空间，没有注册步骤。新安装在首次打开本机页面时自动建立 `admin`，不设置可猜测的默认密码；已有安装沿用原管理员和文献。通过「阅读服务设置 → 成员管理」添加账号。

自动进入只适用于原生启动、配置和实际访问均为回环地址的情况；公网域名不会自动登录。服务器使用离线账号管理命令创建管理员，成员使用管理员发放的账号，不开放注册。

终端保持运行，按 `Ctrl+C` 停止。再次运行同一命令，文献和配置仍然保留。Windows 也可运行 `start.ps1`；Ubuntu 可运行 `bash start.sh`。

如需换端口：

```bash
python run.py --port 8877
```

没有显式配置 `APP_ORIGIN` 时，端口会自动用于本地来源校验；已经复制 `.env` 的情况下，请同步修改其中的 `APP_ORIGIN`。

## 建议按这个顺序测试

1. 直接进入文献库，点击「打开合成示例文献」，检查单栏、双栏和原页显示。示例为自行编写的测试材料。
2. 上传一篇自己常看的英文 PDF，检查正文顺序、段落、公式、图表和原页。已有旧版文献点击「更新基础重排」；上传、基础解析本身不调用外部接口。
3. 在「阅读服务设置」保存服务商连接，再分别选择「逐段翻译」和「文献问答与 AI 重排」的模型，先试译一个段落。也可在阅读页手动选择免 Key 机翻；是否可用取决于当前网络与服务限制。
4. 刷新页面，检查译文缓存、阅读位置和笔记恢复。
5. 测试「翻译全文」和「停止」。已完成译文保留；再次启动会跳过有效缓存。
6. 如需进一步调整分段，在设置 AI 后手动点击「AI 重排」。旧阅读版和译文会保留为可恢复版本，笔记不变。
7. 公网部署验收时，用管理员创建的第二个账号确认私人文献库和服务配置相互独立。

默认单篇上限 50MB / 200 页，个人文件总量 1GB。翻译、AI 重排及问答默认不设每日字数限额，仅保留用量统计。AI 的系统提示、上下文和接口重试也计入发送字符；这不是服务商 token 账单。

若管理员需要控制成员用量，可在 `.env` 显式设置 `DAILY_TEXT_LIMIT` 为正整数字符数（按用户、UTC 日期计量），`0` 表示不限额。旧版若已手动配置 `200000`，需改为 `0` 并重启；服务商自身的余额、上下文窗口及限流规则仍由服务商决定。

## 功能

- 英文在前、中文在后的逐段对照；切换仅原文 / 仅译文、调整字号。
- 机器翻译：MyMemory、Google GTX、Bing 网页接口（实验）、百度、有道智云、Microsoft Translator。前 3 项免 Key，仍受服务商额度与网络限制。
- AI：DeepSeek、智谱 GLM、硅基流动、通义千问、Moonshot、MiniMax、自定义 Chat Completions 兼容接口。各服务商分别保存配置与密钥。
- 翻译与问答 / AI 重排独立选择服务商和模型，同一服务商可复用凭证。翻译默认 6 段并发，可调 1～16；问答有独立后台处理通道。
- 双栏按阅读顺序重排，合并换行、跨栏及跨页续段；公式以原 PDF 片段保真显示，栅格图、矢量图和规则表格放入阅读流。附目录与图表导航。
- 可选 AI 语义分段：只允许模型返回原文行的分组，逐行校验不漏、不重复、不改顺序，失败保留当前阅读版。
- 按段翻译、全文翻译，以及默认关闭、可自行开启的「边读边译」（当前段及后两段）。
- 逐段保存译文和失败原因；停止后续请求；服务重启后恢复排队任务。
- 公式标记丢失、重复或损坏时自动补救，按每个公式的 ID 与数量校验，允许随中文语序调整位置；AI 公式密集段先用短标记分块翻译，校验不通过再使用结构化文字片段、本机回填公式。结构化返回不合法时再逐片翻译，仍受取消、额度和并发约束。补救可能增加接口调用，不会自动切换引擎；公式密集处仍应核对原文。
- 译文缓存区分引擎、模型、API 地址、原文、AI 邻段上下文、术语和提示版本。
- PDF.js 原页核对与段落位置高亮；支持放大查看、25%～400% 手动缩放、适应宽度与双向滚动，Esc 退出放大。放大按新比例重新渲染；修改提取文本，保留原 PDF。
- 文献内搜索、阅读笔记、进度保存、对照 Markdown 导出。
- 文献问答：Enter 发送、Shift+Enter 换行，中文输入法选词时不触发发送；有限段落检索，展示提供给模型的段落和页码。
- 独立账号、私人文献库、加密存储服务配置、CSRF 校验和可选的每日调用字符限额（默认关闭）。

## 接口配置

先在「服务商 API 连接」中保存地址和密钥，再在上方的任务卡中分别选择翻译模型及问答 / 重排模型。AI 的 Base URL 填服务根路径，服务器添加 `/chat/completions`。模型字段可手动填写，默认使用简体中文翻译。

例如，逐段翻译选择智谱 `glm-4-flash`，问答与 AI 重排选择 DeepSeek `deepseek-flash`。同一个智谱 Key 也可以供两个任务使用不同的智谱模型。修改问答模型或并发数不会使翻译缓存失效；修改翻译模型会使用对应的新缓存，旧译文仍保留。旧版本配置在明确分配任务之前继续使用原模型，不自动替换。

翻译并发数建议从 4～6 开始，范围为 1～16。不同文献使用同一翻译连接时共享并发槽；不会一次创建全文数千个请求。已发出的请求允许完成，取消任务后停止新请求、分段续请求及重试。机器翻译更保守：百度串行，MyMemory / Bing / 有道最多 2 段，Google / Microsoft 最多 4 段，并受所设并发数约束。

| 服务 | 默认地址 | 默认模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-flash`，官方当前对应 V4.1 Flash |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash`，也可填写 `glm-4-flash-250414` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | 可编辑，按控制台可用模型填写 |

2026-10-21 核对了 [DeepSeek 官方说明](https://api-docs.deepseek.com/zh-cn/)、[智谱 GLM-4 说明](https://docs.bigmodel.cn/cn/guide/models/text/glm-4) 和 [智谱速率限制](https://docs.bigmodel.cn/cn/api/rate-limit)。模型权限、免费额度、实际费用与并发上限以自己的账号为准；免费 Flash 模型之间的并发权限也可能不同。程序不会自动替换供应商或付费模型。设置页可分别「保存并测试翻译模型」「保存并测试问答模型」，只使用合成句子，不发送论文。

百度需要「通用翻译 API」的 APP ID 和密钥，有道使用智云应用 ID / 应用密钥，Microsoft 使用订阅 Key / 区域。MyMemory、Google、Bing 不需要密钥；Google 和 Bing 可能受限流或网页验证影响，不绕过验证，也不自动换服务商。

原 Zotero 插件也有 Google、Bing、MyMemory；原插件在 Google / Bing 失败后会自动回退 MyMemory。原插件的免 Key 有道使用词典联想查询，仅适合词汇短语，不能作为全文逐段翻译接口。Web 的有道是官方智云全文翻译，需应用密钥。2026-10-21 本机小句测试中，Google / MyMemory 返回 HTTP 429，Bing 返回 HTTP 401；这不是本站每日字数限制，也不能作为其他网络环境的可用性结论。

密钥仅通过设置页发送到当前 PaperPilot 服务，之后由服务器转发 API 请求。数据库中的服务配置经过加密，网页不会读取回原始密钥。密钥输入留空会保留已有值，勾选移除才会删除。

### AI 问答与重排报错

- 本站默认不限每日字数；主页的发送字符为统计，不代表 API 余额。
- 智谱 `429 / 1305` 表示模型服务繁忙，`1302` 表示账号频率限制，`1113` 才是账户欠费；参考 [智谱官方错误码](https://docs.bigmodel.cn/cn/api/api-code)。程序会显示具体原因，不能把这些错误都当成密钥无效。
- 临时的 429 / 500 / 502 / 503 / 504 会等待后重试。翻译使用配置的有界并发，问答单独处理，AI 重排内部仍逐批校验；已移除智谱所有请求共用的全局串行锁。不会自动更换供应商或模型。
- AI 重排按页分批，已校验批次保存在本机。服务出错后再次点击「AI 重排」会复用相同原文、模型及提示版本的已完成批次；全部通过后才替换阅读版。模型只返回段首编号，不重新生成原文。
- 中文问答会匹配英文的方法、结果、结论等章节，优先参考选中段落，并保留原文段落出处。失败问题不放入后续模型对话历史。

本地模型可使用提供兼容接口的服务；需由管理员在 `.env` 设置 `ALLOW_LOCAL_API=true`。默认禁止内网 API 地址。此开关适合你信任的使用者。

## 数据与网络

```text
data/
  paperpilot.sqlite3      账号、文献索引、段落、译文、任务、笔记和阅读进度
  secret.key             服务配置的加密密钥，必须和数据库一并备份
  pdfs/                  原 PDF
  media/                 公式、作者信息、图表的原页 PNG 片段
  backups/               升级前数据库备份（如有）
```

默认路径基于项目目录，支持中文和含空格路径，不依赖启动终端的工作目录。

PDF 原文件及解析图片保存到服务器本地。翻译时发送目标段落，行内公式以保护标记代替图片；AI 翻译还会发送前后少量上下文和术语。AI 重排发送按页分批的提取文本，问答发送有限摘录及少量对话历史。完整 PDF 和图像不会直接发送到当前文字接口。

后端读取 `HTTPS_PROXY` / `HTTP_PROXY` 作为 API 出站代理，本地接口始终直连；不继承系统 `NO_PROXY` 中可能不兼容的 IPv6 写法。Tunnel 只提供网站入口，Ubuntu 到翻译接口的连通性需要另测。

## 当前边界

- 适合带文字层的常见单栏、双栏论文。基础重排依赖原页坐标、字体和图形，复杂版式仍需原页核对；可手动修正文本或尝试 AI 分段。
- 公式是原页保真片段，未转换成可编辑 LaTeX；AI 文字问答看不到图表、公式图片的内容。复杂无边框表格、叠图与不规范图注可能漏识别。
- 扫描件提示需要 OCR，首版不执行重型 OCR。
- 问答采用有限摘录检索；中文问题未必能命中相关英文段落。优先选段提问，关键结论回原文确认。
- 停止翻译在当前接口请求结束后生效。进程异常退出时，正在进行的请求可能在恢复后重发，无法保证外部接口只计费一次。
- 适合单台服务器和少量用户，启动 **一个**应用进程。任务队列是 SQLite 持久化 + 应用内异步执行。Docker Compose 的 PDF 解析运行在独立容器中，无公网出口、不挂载账号数据库和密钥；原生本机测试使用受超时、输出大小限制的子进程。
- 当前账号不包含公开注册、邮件找回、文献分享或 Zotero 同步。
