## 公式翻译与 PDF 放大

- 公式按每个 ID 的数量校验，防止缺失、重复和新增；允许中文正常语序调整公式位置。
- 公式密集段先按句子分块，使用短引用，严格校验后恢复原公式 ID；失败时使用结构化文字片段及逐片翻译补救。
- 补救不会自动更换供应商。自动测试覆盖损坏标记、结构化失败、上下文标签泄漏、取消及接口错误。
- PDF.js 根据新比例重新渲染；放大查看、25%～400% 手动缩放、适应宽度、双向滚动、Esc 退出及段落高亮已在浏览器验证。
- 1280×720 桌面视口中放大框为 1248×688；390×844 手机视口中铺满窗口，PDF 内部横向滚动不会撑宽网页。验证时浏览器 error / warn 为空。

## 模拟检查与真实 API 的区别

自动测试中的供应商请求均使用模拟响应，不证明真实账户权限或接口可用性。

本地另做过已授权的真实 API 检查：

- 智谱 `glm-4-flash` 短段并发翻译及 DeepSeek 独立问答可用。
- 真实公式密集段验证保留了全部 20 个公式 ID；该次 4 个分块调用约 32 秒。此结果只代表该次调用，不保证其他文献的速度或翻译语义准确性。
- 免 Key 机翻在当前网络下可能遇到 HTTP 429 / 401；程序保留错误，不绕过网页验证，不自动更换引擎。
- PDF 公式为原页图片，文字模型看不到公式图像内容；术语、比较方向和关键结论仍须核对原页。

真实凭证、用户文献、数据库、截图和详细运行记录均保留在本机，不进入公开仓库。
